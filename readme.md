# HSRN Corelink Plugin POC

## Goals

1. Create infrastructure and example to let developers see how to structure/add plugins to hsrn.nyu.edu's plugin registry
2. Sufficient Documentation on manifest creation and manipulation for arguments needed to link plugins
3. Teach future HSRN lab members how to link plugins to senders and plugins on the kubernetes cluster with our simple demo.

### POC

Take imaging and first step is a grayscale filtering (a simple plugin) then send over to a computer vision algorithm identifying code

#### installation

```Run pip install -r requirements.txt```
